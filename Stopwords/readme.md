# Stopward 
this is a kind of filtering algorithm which basically filter out the meaning full thing from the sentense.because they appear so frequently so they don't hold enough semantic values and they use pre-defined library.  
Sentence: "The cat is on the mat."  
Library Work:  "The"? → Cut  

"cat"? → Keep  

"is"? → Cut  

"on"? → Cut  

"the"? → Cut  

"mat"? → Keep  

Result: ["cat", "mat"]

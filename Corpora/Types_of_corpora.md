# Types of Corpora
1.Text Corpora 
2.Multimodal Corpora 
3.Parallel Corpora 
4.Time-Series Corpora
5.Annotated Corpora
Let's talk in detail about these topic
* **Text Corpora**:it contain the raw text data that don't have any label or extra information at all.
  for ex: Ram is going to Delhi.
* **Multimodal Corpora**:Mean the data is  in multiple form such as image,audio,video etc
* **Parallel Corpora**:Mean the data is in one language then it also present in multiple language to.
* **Time-Series Corpora**:When the data is not only the text but the information of the chronological order
  (basically time)
* **Annotated Corpora**:The data is actually in text form but have extra information,labels present that is called annotated corpora
  for ex:
  Himxhuydv runs faster than rahul.(raw corpora)
  Himxhuydv(Person) runs(Verbs) faster(Verb) than(Adjuctive) rahul(Person).
